# Сайт 3dhouse.kg

Магазин 3D HOUSE (Бишкек): 3D-принтеры, пластик, аксессуары.

- `src/site.html` — исходник главной страницы (каталог, корзина, квиз, данные из CRM).
- `build.py` — собирает сайт в `docs/`: главная, страницы товаров, карта сайта.
- `docs/` — готовый сайт, его раздаёт GitHub Pages на домене 3dhouse.kg.

Обновление: изменить `src/site.html`, запустить `python3 build.py`, закоммитить `src/` и `docs/`.
